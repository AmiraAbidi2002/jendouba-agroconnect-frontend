# Jendouba AgroConnect - Frontend

## 1. Overview
Jendouba AgroConnect Frontend is a web application connecting farmers and buyers in the Jendouba region.  
Built with **React**, it provides a responsive and interactive interface to:  
- View and manage crops  
- Chat between farmers and buyers  
- Display 7-day weather forecasts  
- Show farm locations on a map  

## 2. Features
- JWT-based authentication (Login / Register)  
- User profiles for Farmers and Buyers  
- Crop listing management (create, read, update, delete)  
- Messaging system between users  
- 7-day weather forecast widget  
- Map integration for farm locations  
- Responsive UI using Tailwind CSS  

## 3. Technologies
- React + Hooks  
- React Router for navigation  
- Context API (or Redux) for state management  
- Axios for API calls  
- Tailwind CSS  for styling  
- Leaflet.js for map visualization  

## 4. Setup Instructions

### 4.1 Prerequisites
- Node.js v18+  
- npm or yarn  
- Backend API running on http://localhost:8080  

### 4.2 Installation
1. Clone the repository:
```bash
git clone https://github.com/AmiraAbidi2002/jendouba-agroconnect-frontend.git
cd jendouba-agroconnect-frontend
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Configure environment variables:
Create a .env file in the root directory with:
```bash
REACT_APP_API_URL=http://localhost:8080/api
REACT_APP_WEATHER_API_KEY="def24126ddcdbcea53a18b62e956302f"
```

### 4.3 Running the App Locally
```bash
npm start
# or
yarn start
```
Open http://localhost:3000  in your browser.

### 4.4 Build for Production
The production-ready files will be generated in the build/ folder.
```bash
npm run build
# or
yarn build
```

## 5. Project Structure
src/
  components/      # Reusable components (Buttons, Forms, etc.)
  pages/           # Page components (Home, Dashboard, CropList, AuthPage)
  context/         # Context API providers for state management
  api/             # Axios API calls
  assets/          # Images, logos, icons
  App.js           # Main App with routing
  main.js         # Entry point

## 6. Notes

- Make sure the backend API is running before testing frontend features.
- Map integration requires internet access for tiles.
- Use a valid OpenWeather API key to enable weather features.
